# To-Do Application

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Shubham9599/Todo-Application)

A **full-stack To-Do web application** built with **Java, Spring Boot, MySQL, and Thymeleaf**. This app allows users to manage tasks efficiently with **CRUD operations** and a **responsive UI**.

---

## Features

- Create, read, update, and delete tasks  
- Mark tasks as completed or pending  
- Responsive and user-friendly UI using **HTML, CSS, and Thymeleaf**  
- Secure and efficient backend with **Spring Boot and MySQL**  
- Modular code for easy maintenance and scalability  

---

## Tech Stack

- **Backend:** Java, Spring Boot, Spring MVC  
- **Frontend:** HTML, CSS, Thymeleaf  
- **Database:** MySQL  
- **Tools:** Maven, Git, Postman
